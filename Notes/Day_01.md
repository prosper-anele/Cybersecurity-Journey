## What I Learned

### What is a Network?
A network is a group of devices connected together so they can communicate and share data.

### What is an IP Address?
An IP address is a unique address assigned to a device on a network so other devices can find and communicate with it.

### Public vs Private IP
- Private IP: Used inside local networks like home or work Wi-Fi.
- Public IP: Used to communicate over the Internet.

### What is DNS?
DNS (Domain Name System) translates website names into IP addresses.
